# Maintainers

RepoGym is currently maintained by the repository owner. Maintainers review compatibility,
security-boundary, task-format, and release changes before merge.

Changes to persisted schemas, plugin contracts, executor trust boundaries, scoring semantics, or
release automation require an ADR or an update to an existing ADR. Security reports follow
`SECURITY.md`; general support and contribution paths are described in `SUPPORT.md` and
`CONTRIBUTING.md`.

As the maintainer group grows, this file will record named maintainers, review areas, and the
process for adding or removing maintainers.
