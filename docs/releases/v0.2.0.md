# RepoGym v0.2.0

RepoGym v0.2.0 expands the initial reproducible grading toolkit into a versioned, automatable task
platform.

Highlights include versioned TaskSpec migrations and portable task bundles; bounded and cancellable
execution; structured command, environment, artifact, and per-test evidence; deterministic run and
batch comparison; JUnit and SARIF reports; stable automation exit codes; atomic execution caching;
versioned plugin contracts; task scaffolding and author lint; and an explicit, fail-closed Docker
backend with resource and network policy.

The release supports Python 3.11 and 3.12 on Ubuntu and Windows. `LocalExecutor` remains the default
and is not a sandbox. Docker execution must be selected explicitly and still relies on the security
of the configured image and daemon.

Install the attached wheel with:

```bash
python -m pip install repogym-0.2.0-py3-none-any.whl
repogym version
```

See `CHANGELOG.md` for the complete change list and `docs/security-model.md` before executing
untrusted task code.
